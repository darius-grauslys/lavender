# Data Structures

### Linear (Data structure)
Each element has exactly one owner, no more or less.

### Affine (Data structure)
Each element has at most one owner (perhaps no owner.)

### Cons-list
Singly linked list of cons cells, a cons cell is a pair, a list ia a nesting terminated with 'nil'.

### Trie
Keyed by path components.

### Hash Trie
A trie index by hashes (persistent, log-depth).

### B-tree
Self balancing for block storage.

### Finger Tree
A sequence of amortized O(log n) ops at both ends.

### Zipper
A structure supporting traversal with a focus+context.
