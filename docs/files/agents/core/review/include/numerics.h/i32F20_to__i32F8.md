# i32F20_to__i32F8

**File of origin:** `core/include/numerics.h`

## Semantic

Converts a 20-bit fractional fixed-point value (`i32F20`) to an 8-bit fractional fixed-point value (`i32F8`) by performing an arithmetic right shift of 12 bits (20 − 8 = 12 fractional bits removed).

## Pre-conditions

1. `x` is a valid `i32F20` value (a 32-bit signed integer representing a fixed-point number with 20 fractional bits). No additional constraints on range or sign.

## Post-conditions

1. Returns a `Signed_Index__i32` (i.e., `int32_t`) value representing the same numeric quantity expressed in 8-bit fractional fixed-point format (`i32F8`).
2. The result is the mathematically correct conversion of the input, preserving sign and truncating (toward zero) the 12 least-significant fractional bits that are discarded.

## Correctness Verdict

**Correct**

## Semantic Alignment

The implementation correctly converts from `i32F20` to `i32F8` by right-shifting by 12 bits. This is the correct shift amount: `i32F20` has 20 fractional bits and `i32F8` has 8 fractional bits, so 12 fractional bits must be removed. The companion function `i32F8_to__i32F20` shifts left by 12 (`FRACTIONAL_PERCISION_12__BIT_SIZE`), confirming the bidirectional consistency of this conversion pair.

## Implementation Correctness

- **Type compatibility:** The input parameter `x` is of type `i32F20` (typedef `int32_t`), and the return type is `Signed_Index__i32` (typedef `int32_t`). Both `i32F20` and `i32F8` are `int32_t`, so no implicit conversions or truncation occur.
- **Arithmetic right shift:** The `ARITHMETRIC_R_SHIFT` macro correctly handles negative values by negating, shifting, and re-negating, avoiding compiler-specific behavior for right shifts of negative numbers. The shift amount (12) is within the valid range for a 32-bit integer (0–31), so no undefined behavior occurs.
- **Validation:** No validation is needed for this function's role; it is a pure numeric conversion with no invalid input states.

## Side Effects

No side effects. This is a pure function: it takes a value, performs a computation, and returns a result without modifying any state.
