# Tools

Engine tooling. Add `./tools` to your `PATH` to use it.

> Documentation for this section is in progress.

| Tool | Purpose |
|------|---------|
| `lav_new_project` | Scaffold a new Lavender project. |
| `lav_build` | Build a project (e.g. `lav_build -e PLATFORM=sdl`). |
| `lav_grit` | Grit tooling (details TBD). |
