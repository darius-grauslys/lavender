i32_to__i32F20 — core/include/numerics.h

Converts a plain 32-bit signed integer into a 32-bit fixed-point value with 20 fractional bits by left-shifting the integer by 20 positions.

Pre-conditions:
1. x is a valid Signed_Index__i32 (int32_t) value. No null or range constraints apply — the parameter is a value type.
2. The caller should be aware that the result is x multiplied by 2^20; if x exceeds 11 bits of magnitude (i.e., |x| > 2047), the result may overflow the 32-bit range and wrap.

Post-conditions:
1. Returns an i32F20 (int32_t) equal to x << 20, preserving the sign of x. The conversion is lossless only when x fits within the integer portion of the fixed-point format (i.e., |x| < 2^12).

The shift amount (20) is less than the bit-width (32), so no over-shifting occurs. No null dereference, no pointer arithmetic, no out-of-bounds access.
