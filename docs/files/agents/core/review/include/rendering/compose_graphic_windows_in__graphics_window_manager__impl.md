compose_graphic_windows_in__graphics_window_manager — core/source/rendering/graphics_window_manager.c (lines 761–790)

Iterates the manager's sorted graphics-window pointer array from index 0, invoking each window's f_PLATFORM_compose_gfx_window callback for windows that have the COMPOSE_DIRTY flag set. Stops at the first NULL slot (or a window lacking a compose callback). Non-dirty windows are skipped via continue.

Pre-conditions:
1. p_game must be a non-null pointer to an initialized Game. It is dereferenced without a null check to access gfx_context (consistent with the codebase convention — callers in the scene loop always supply a valid Game).
2. The game's Gfx_Context must be initialized so that get_p_gfx_context_from__game yields a valid context.
3. The Graphics_Window_Manager within the Gfx_Context must be initialized so that ptr_array_of__sorted_graphic_windows is in a valid state.
4. The sort invariant must hold: all non-NULL entries in ptr_array_of__sorted_graphic_windows precede all NULL entries. This is maintained because sort_graphic_windows_in__graphic_window_manager is called after every allocation (_allocate_graphics_window_from__graphics_window_manager, line 187), after every release (release_graphics_window_from__graphics_window_manager, line 410), and after parent-child reassignment (line 276). The comparator pushes NULL entries toward the end of the array.

Post-conditions:
1. Each Graphics_Window in the sorted array (from index 0 up to, but not including, the first NULL slot) whose COMPOSE_DIRTY flag was set has had its f_PLATFORM_compose_gfx_window function pointer invoked with (p_game, p_gfx_window).
2. Windows are composed in sorted order — children before parents — matching the documented ordering constraint (per the comment in render_graphic_windows_in__graphics_window_manager at line 724).
3. The COMPOSE_DIRTY flag is evaluated via is_graphics_window_in_need_of__composition, which may also set the flag if the window's UI_Manager is dirty (side effect of the helper — see Section 8).
4. The function returns void; no return value to inspect.

Correctness Verdict: Correct

Semantic Alignment:
The function faithfully implements its intent: compose every graphics window that needs it, in sorted order. The key semantic distinction from the sibling render function is the is_graphics_window_in_need_of__composition guard, which restricts composition to dirty windows only — this is correct because composition (re-rendering a window to a framebuffer/texture) is an expensive operation that should only occur when something has changed, whereas rendering (drawing the texture to screen) happens every frame unconditionally. The loop bounds are MAX_QUANTITY_OF__GRAPHICS_WINDOWS (8), which is the size of the ptr_array_of__sorted_graphic_windows array. The sorted array is queried via get_p_graphics_window_by__sorted_index_from__manager, which bounds-checks the index and returns NULL for out-of-range access. The f_PLATFORM_compose_gfx_window callback is the same typedef as f_PLATFORM_render_gfx_window (both are of type f_PLATFORM_render_gfx_window, typedef'd in defines.h:2478 as void (*)(Game*, Graphics_Window*)), so a Graphics_Window in the sorted array always has a non-NULL compose callback if it was properly initialized (the default initializer in graphics_window.c:28 sets both callbacks). The early break on a NULL window or NULL callback is correct: because the sort invariant guarantees all non-NULL entries are contiguous from index 0, the first NULL slot marks the end of active windows. The continue on a non-dirty window is also correct: it skips the window but continues scanning subsequent indices, and since non-NULL entries are contiguous, the loop will eventually hit the NULL boundary and break (or exhaust all indices). There is no scenario in which continue causes the loop to skip past the NULL terminus.

- Invokes is_graphics_window_in_need_of__composition for each non-NULL window, which has its own side effect: if the window's UI_Manager is dirty, it calls set_graphics_window_as__in_need_of__composition to set the COMPOSE_DIRTY flag.
