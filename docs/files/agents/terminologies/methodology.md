# Methodology

### Protocol First Design
Define protocols/interface first before any implementation.
Decouples shape from realizations.

### Refinement Calculus
Start abstractly from the spec, refine step-wise to code.
Each refinement preserves a stated invariant.

### Bi-directional Development
Top-down decomposition + bottom up composition in alternation.
Catches gaps in spec and implementation early.

### Invariant Driven Development
State Invariants upfront, verify after every change.

### Scaffolding
Build the skeleton (types, signatures, stubs) before bodies.

### Test Driven Development
Write tests before code.

### Type-driven Development
Let the type system guide implementations.

### Interface Development
Design APIs before implementations.

### Literate Programming
Code as a document with prose.

### Provenance Tracking
Record why each decision was made.

### Specification-First
Write the spec, agents implement.

### Reflection
The system reasons about itself.
