# Algorithms

### Backtracking
Try, undo on failure.

### Greedy
Locally optimal choices.

### Branch and Bound
Prune branches that cannot improve.

### Bisection
Halve the search space.

### Divide and Conquer
Split, solve, combine.

### Dynamic Programming
Memoize overlapping subproblems.

### Sliding Window
Scan with a moving window.

### Two Pointer
Iterate with two indicies.

### Batched
Group operations.

### Pipelined
Sequential stages.

### Short-Circuit
Stop at first success/failure.

### Streaming
One at a time, bounded memory.

### Fork-join
Split work, combine later.

### Map-reduce
Map: Apply a function ot each element independently to form a new collection.
Reduce: Combine elements with Associative + Commutative binary operators to a single value.

### Topological Sort
Order by dependencies.

### Tracing
Instructment before optimizing.

### Monotonic
Preserves partial order; never decreases a designated measure.
