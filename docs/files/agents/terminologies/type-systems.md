# Type Systems

### Abstract Date Type (ADT)
Behavior specified, representation hidden.

### Tagged Union
A value is one of several variants with a tag.

### Product Type
A record/tuple, a compond type from cartesian product.

### Algebraic Data Type
Sums of products. A type built from sums and products, possibly recursive.

### Functorial
A contianer that supports a function preserving map.

### Monadic
A functor with flatten/join supporting sequential composition.

### Strict
Forces evaluation of its arguments.

### Total
Defined for every input in its domain.

### Type Invariant
A property enforced by the type system itself.
